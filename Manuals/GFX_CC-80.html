CC-80

A pocket-calculator chord generator that writes voice-led chords into a MIDI item at the edit cursor.

Overview

CC-80 is a chord scratchpad in the style of an 80s pocket calculator. Build a chord from a root (A - G, flat or sharp), a quality (maj, min, dim, aug, sus4), a seventh and an extension (9, 11, 13), choose a duration and press = to write it into a MIDI item at the edit cursor. The cursor then moves on, ready for the next chord.

Each new chord is voiced close to the last one (voice leading), so a progression moves smoothly instead of jumping around. REST skips time, the memory keys store a sequence of chords and write it out in one go, and DRIFT humanises the velocity and timing.

It is a ReaScript, not a plugin: it runs in its own window and needs the free ReaImGui extension.

Reach for it for

  • Sketching chord progressions quickly
  • Writing pad and keys parts with smooth voice leading
  • Trying out extended chords without working out the notes
  • Storing a progression and writing it again elsewhere in the song

Installing

1. Install ReaImGui (once)

  1. If you don't have ReaPack yet, install it from reapack.com and restart REAPER.
  2. Open Extensions > ReaPack > Browse packages.
  3. Search for ReaImGui (from the ReaTeam Extensions repository), right-click it and choose Install, then Apply.
  4. Restart REAPER. CC-80 needs ReaImGui 0.9 or newer; if it is missing, the script tells you so when you run it.

2. Load the script

  1. Open Actions > Show action list.
  2. Choose New action > Load ReaScript and pick GFX_CC-80.lua.
  3. Select it in the list and press Run. The CC-80 window opens.
  4. To open it quickly next time, assign it a shortcut or add it to a toolbar from the action list.

Where the chords go

  • If a MIDI editor is open, the chords go into the take it is editing.
  • Otherwise they go on the first selected track: into the latest MIDI item that starts at or before the edit cursor (as long as it doesn't end more than 8 beats before it), or into a new MIDI item.
  • The item is lengthened automatically if the chord runs past its end.
  • Notes are written at the edit cursor on MIDI channel 1 at velocity 100, and the edit cursor moves to the end of the chord. Each entry can be undone.

Controls

The display

Top line
The chord name as you build it (e.g. Cmaj7), or ERR.
Second line
The chord spelled note by note (e.g. C - E - G - B), or the error message.
Bottom line
Left: the current duration. Middle: Mn when chords are stored in memory, Dnn when DRIFT is on. Right: the last action (READY, INS Am7, REST 1/4 and so on).

Building a chord

Keys that hold a setting have a small red light.

C D E F G A B
Choose the root. Pressing a root always starts a new chord.
b / #
Flat or sharp the root. Press again to cancel.
maj / min / dim / aug / sus4
The quality. With none chosen, the chord is major.
7
Adds a seventh: a flat 7th on most chords, but a major 7th after maj (maj + 7 = maj7) and a diminished 7th after dim (dim7).
M7
Adds a major 7th.
m7
The minor-seventh chord: it implies min (so A + m7 = Am7); with dim it gives the half-diminished m7b5.
9 / 11 / 13
Adds an extension; the last one pressed wins. An extension brings its seventh with it (a major 7th after maj, otherwise a flat 7th) and the 9th. 11 drops the major 3rd to avoid a clash; 13 leaves out the 11th.

Some combinations are refused, with a message on the display: two different qualities or sevenths, m7 with maj, aug or sus4 (m7 CLASH), any extension on dim (DIM EXT), and 11 on sus4 or aug.

Duration and writing

1/1 / 1/2 / 1/4 / 1/8
The length of the next chord or rest: whole note, half note, quarter note or eighth note.
=
Writes the chord at the edit cursor and moves the cursor on.
REST
Moves the edit cursor on by the current duration without writing anything.
CLEAR
Clears the chord you are building. Pressed again with nothing entered, it resets the voice leading (VOICE RESET), so the next chord is voiced fresh around the middle of the range.

Memory and drift

M+
Stores the current chord, with its duration, at the end of the memory.
MR
Writes every stored chord in order at the edit cursor (its light shows the memory holds something).
MC
Clears the memory.
DRIFT
Steps through 0, 25, 50, 75 and 100%. It humanises each note: at 100% velocity varies by up to 25 either side of 100 and timing by up to 12 ms.

The duration, DRIFT setting and memory are remembered the next time you run the script.

Keyboard shortcuts

While the CC-80 window has focus: A - G choose the root, Enter is =, Space is REST, Backspace is CLEAR, and 1, 2, 4 and 8 choose the duration.

Voice leading

CC-80 picks the inversion and octave of each chord that moves the fewest semitones from the previous one, keeping the notes between E2 and C6 and avoiding close, muddy intervals low down. The first chord (or the first after VOICE RESET) is placed around the middle of that range in root position where it can.

Messages

NO ROOT / NO CHORD
Choose a root first.
2 QUALITIES / 2 SEVENTHS
Only one quality and one seventh per chord - press CLEAR or a new root to start again.
MEM EMPTY
MR was pressed with nothing stored.
NO TRACK
No MIDI editor is open and no track is selected.
NOT MIDI / NO ITEM
The target take is not MIDI, or a new item could not be made.

Tips

  • Open the MIDI editor on the item you are working on and the chords go straight into it.
  • Store a progression with M+ as you try it out, then place the edit cursor at the next section and press MR to write it all again.
  • Use REST between chords for rhythmic stabs, or 1/8 chords for pushes before the bar.
  • If a progression has drifted too high or low, press CLEAR twice to reset the voice leading.
